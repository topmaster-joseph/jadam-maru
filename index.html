OPEN KITCHEN

우리 매장 실시간 화면

  • 개인정보 보호조리대 등 공개 허용 구역만 송출
  • 안전한 중계CCTV 비밀번호와 원본 RTSP 주소는 비공개
  • 무료 기반MediaMTX 또는 go2rtc로 HLS/WebRTC 변환 가능

고객·직원 얼굴이 식별되는 구역은 촬영 동의와 안내 표지 없이 공개하면 안 됩니다. 영상은 녹화보다 실시간 확인 중심으로 운영하는 것을 권장합니다.

LIVE CAMERA SETUP

기존 CCTV를 홈페이지에 안전하게 연결하는 방법

  1. 매장 내부망에서 CCTV의 RTSP 주소를 확인합니다.
  2. 무료 프로그램 MediaMTX 또는 go2rtc를 Docker로 실행합니다.
  3. 외부에는 비밀번호가 포함된 RTSP가 아닌 HLS/WebRTC 주소만 공개합니다.
  4. Cloudflare Tunnel과 접근 정책을 적용한 뒤 이 페이지의 영상 주소에 연결합니다.

실제 연결에는 CCTV 제조사·모델, 매장 인터넷 환경, 공개할 카메라 1대의 정보가 필요합니다.
