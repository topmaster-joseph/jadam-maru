안심하고 주문할 수 있는
우리 매장의 실시간 모습

  • 개인정보 보호조리대처럼 공개가 허용된 구역만 보여 줍니다.
  • 안전한 영상 중계CCTV 비밀번호와 원본 주소는 외부에 공개하지 않습니다.
  • 무료 기반 프로그램MediaMTX 또는 go2rtc로 HLS·WebRTC 영상을 제공할 수 있습니다.

고객이나 직원의 얼굴이 식별되는 구역은 촬영 동의와 안내 없이 공개하지 않습니다. 녹화 영상보다 실시간 확인 중심으로 운영하는 방식을 권장합니다.

LIVE CAMERA SETUP

기존 CCTV를 홈페이지에 안전하게 연결하는 방법

  1. 매장 내부망에서 CCTV의 RTSP 주소를 확인합니다.
  2. 무료 프로그램인 MediaMTX 또는 go2rtc를 Docker로 실행합니다.
  3. 비밀번호가 포함된 원본 주소 대신 HLS 또는 WebRTC 주소만 외부에 제공합니다.
  4. Cloudflare Tunnel과 접근 정책을 적용한 뒤 이 페이지의 영상 주소에 연결합니다.

실제 연결을 진행하려면 CCTV 제조사와 모델명, 매장 인터넷 환경, 공개할 카메라 정보가 필요합니다.
